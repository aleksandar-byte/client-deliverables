# Michigan Glass Coatings — intent, clusters and internal links

Date: 3 October 2026. Existing-site architecture review for Nick. No new pages, redirects, menu edits or content removals are approved by this report.

## Strategic direction

Use the existing service × audience × location structure. Michigan Glass Coatings is an architectural film installer, not an automotive tint shop or ecommerce catalog. Generic tinting demand should not automatically become an automotive target or inflate building-film opportunity estimates.

The immediate job is to repair wrong copy/routes within the existing structure. Broad expansion into near-identical city/service pages is not justified by the evidence gathered here.

## Possible overlap requiring a decision, not automatic consolidation

### Legacy 3M residential page versus modern Residential hub

Both discuss residential film benefits, but one can serve product-brand education and the other local installation/quote intent. The legacy page still had **1 click/196 impressions** in the saved current GSC page report; `/residential/` had **1/268**. Review the query sets, body uniqueness and current internal links before deciding between retaining a supporting guide, repositioning it, or consolidating it. No content should be deleted simply because it is older or shorter.

### Generic 3M page versus Services/homepage

`/3m-window-films/` had **2 clicks/135 impressions**. It has a product-brand overview role that is not necessarily the same as choosing a service or finding a local installer. If retained, add useful contextual links to the modern relevant film pages after confirming current body links. If consolidation is proposed later, preserve useful product context and redirect only to a genuinely matching destination.

### Location pages versus service pages

Regional pages combine several services; individual film pages explain the solution across the served area. This is a legitimate hierarchy. Shared service vocabulary is not evidence of cannibalization. Correct reused paragraphs first, then examine query-level competition before changing ownership.

## Demand and SERP validation limits

The four initial keyword SERP evidence files failed or partly failed relevance checks. For example, the requested Detroit commercial query returned dictionary/typography/whaling results; the residential Detroit query returned Xiaomi/Michigan government results. These cannot be used for a top-ten intersection, competitor gap, local rank or numeric cannibalization score. The Grand Rapids commercial result also mixed automotive intent.

Consequently this report provides an evidence-backed existing-page intent map, not a fabricated pairwise SERP-overlap matrix. Use the keyword specialist's corrected snapshots if recovered. Before a new content brief or redirect, collect the actual query pair and compare relevant result URLs/page types; retain distinct informational and installation intents even when they share words.
