# Dental Homepage Content Intake

Use this checklist before writing or building the homepage. Record confirmed
facts and their sources. Leave unknown items blank or mark them for confirmation;
do not replace missing information with generic marketing copy.

## Minimum Information Required To Start

### 1. Practice identity

- [ ] Exact public practice name
- [ ] Legal business name, when different
- [ ] Primary dental category or practice type
- [ ] Short, verified description of the care scope
- [ ] Primary patient audience, such as adults, families, children, or all ages
- [ ] Primary city and state
- [ ] Street address and ZIP code
- [ ] Main phone number
- [ ] Appointment-request URL or confirmed booking method
- [ ] Current opening hours
- [ ] Current homepage URL and preferred canonical URL

### 2. Dentists and care responsibilities

For every dentist appearing on the homepage:

- [ ] Full professional name and credentials
- [ ] Professional title or role
- [ ] Treatments or service areas they personally provide or plan
- [ ] Relevant education, residency, postgraduate training, or experience
- [ ] Plain-language meaning of each highlighted credential
- [ ] Internal dentist biography URL
- [ ] Authoritative credential or institution URL, when useful
- [ ] Approved first-party portrait and source location
- [ ] Confirmation that the portrait may be used

### 3. Services and internal links

- [ ] Verified service hubs actually offered by the practice
- [ ] Live URL for every approved service hub
- [ ] Priority treatment, if one deserves a dedicated homepage section
- [ ] Live URL for the priority treatment page
- [ ] Common patient concerns connected to the most relevant service hub
- [ ] Most important specific treatment link for each concern, when applicable
- [ ] Services or pages that must not be promoted from the homepage

### 4. Practice distinctions and patient benefits

- [ ] One meaningful hero benefit, if supported
- [ ] Three to five short trust facts
- [ ] Practice history or years in operation
- [ ] Relevant provider experience
- [ ] Useful access facts: emergencies, family scheduling, languages, or accommodations
- [ ] Technology or clinical resources worth mentioning
- [ ] Source for every distinctive claim

Do not use a credential as a promise of quality, safety, eligibility, or outcome.

### 5. Appointment and new-patient information

- [ ] How online and telephone appointment requests are confirmed
- [ ] When a patient should call instead of using the online form
- [ ] Urgent dental instructions
- [ ] New-patient forms or resource URLs
- [ ] Confirmed insurance participation wording
- [ ] Estimate, financing, and payment information
- [ ] What patients should bring or prepare, when confirmed

### 6. Location and access

- [ ] Verified map destination
- [ ] Parking information
- [ ] Accessibility information
- [ ] Building, suite, entrance, or landmark details
- [ ] Top three relevant secondary locations for direction links
- [ ] Reason and source used to select each secondary location
- [ ] Valid route URL from each origin to the practice

Nearby communities are direction origins, not additional office locations.

## Information Required Only When A Section Is Used

### Practice evidence

- [ ] Original office, team, technology, or case media
- [ ] Asset source, owner, consent, and permitted use
- [ ] Exact attributable review excerpt and source URL
- [ ] Specific claim supported by each image, review, case, credential, or technology

Remove the evidence section when useful, publishable evidence is unavailable.

### Priority treatment

- [ ] Verified demand or business reason for featuring the treatment
- [ ] Dentist responsible for the treatment
- [ ] Relevant credential, technology, case, or original media
- [ ] Complete service page that carries candidacy, risks, process, and recovery detail

Remove this section when any essential support is missing.

### FAQs

- [ ] Real pre-appointment questions not already answered elsewhere
- [ ] Verified direct answer for every question
- [ ] Useful supporting destination, when additional detail helps

Do not create FAQs from keyword variations or repeat information from the page.

### Recent articles

- [ ] Active blog or patient-resource hub URL
- [ ] Three recent, relevant, indexable posts
- [ ] Accurate title, URL, publication date, category, excerpt, and featured image
- [ ] Dynamic query rules and exclusions for test, thin, duplicate, unrelated, or noindex posts

## SEO And Technical Handoff

- [ ] Primary homepage topic and location
- [ ] Proposed title and meta description
- [ ] Canonical URL
- [ ] Exact NAP used across page, schema, and official profiles
- [ ] Practice/LocalBusiness schema type and entity identifier
- [ ] Dentist schema entries and provider-practice relationships
- [ ] Authoritative `sameAs` or credential profile URLs
- [ ] Internal-link map
- [ ] Image filenames and alt text
- [ ] Facts still requiring client confirmation
- [ ] Final content and media approvals

## Source Record For Important Claims

For each non-obvious claim, record:

- Claim
- Proposed wording
- Source URL or file
- Source type
- Confidence: confirmed, probable, conflicting, or unverified
- Owner or approver
- Date checked
- Allowed public wording
